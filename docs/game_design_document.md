> 版本：1.0

## 一、游戏概述

### 1.1 基本信息

- **游戏名称**：三人竞技棋（Three Against One）
- **游戏类型**：回合制策略棋盘游戏（Hotseat / 网络联机）
- **运行平台**：Windows（Godot 4.6）
- **玩家数量**：3 人（固定阵营）
- **核心玩法**：三位玩家在 100×56 共享网格地图上采集资源、建造建筑、招募军队、研发科技，最终通过征服或计分取得胜利。

### 1.2 核心循环

```
每回合 → 获得 AP → 移动单位 → 采集/建造/招募/战斗 → 结束回合
       ↕
   阶段进行 → 哥布林海克斯事件 → 中立单位行动 → 回合计分
```

- **AP 系统**：每回合刷新 25 AP，上限 50
- **总回合数**：75 回合（5 阶段 × 15 回合/阶段）
- **回合顺序**：精灵(0) → 矮人(1) → 兽人(2) → 中立单位行动 → 回合结束

### 3.4 地形生成流程（6 阶段）

1. **Phase 1 — 山脉**：中央巨龙山峰 + 通道，附带 4.2% 概率的遗迹（RUINS）散布
2. **Phase 2 — 资源环**：山脉外围资源带
3. **Phase 3 — 海洋**：无限海边界 + 悬崖
4. **Phase 4 — 领地**：三方阵营领地分配 + 海拔 + 区域标签
5. **Phase 5 — 禁行区**：DRAGON_MOUNT / VOID 障碍物散布
6. **Phase 6 — 地形赋值**：根据海拔 + 坡度在各区域内赋地形类型

### 5.2 建造规则

- **AP 消耗**：2 AP / 次
- **地形限制**：必须在可建造地形上（平原/森林/山地/通道/遗迹）
- **领地限制**：必须在己方领土内
- **数量限制**：每种建筑有阵营上限
- **锚点检测**：2×2 主城需 4 格空地，1×1 建筑需 1 格空地
- **入驻系统**：工人可入驻经济/工业/核心建筑，每轮修复 1 HP

### 5.3 建筑渲染

建筑通过 `_draw()` 绘制，纹理配置在 `data/building_texture_fit.json` 中定义，包含占地面积(footprint)、偏移量(offset)、缩放(scale)和纹理路径(texture path)。

### 5.4 战场迷雾

建筑在战争迷雾中不可见，迷雾消散后才渲染。

### 6.6 战斗系统

- **模式**：实时决斗（Timer 1s 交替攻击）
- **攻击顺序**：先手方先攻击 → 交替进行
- **伤害公式**：攻击 - 减伤（最低 1 点）
- **攻击间隔**：单位固有属性，默认 1.0s
- **射程**：近战 1 格，远程 3~4 格
- **视觉效果**：闪烁/震动/伤害数字，基于 SpriteStrip 的 hurt/attack/death 动画
- **命中检测**：战斗前进行视线（Line of Sight）检查

## 二十一、视觉与渲染规范

### 21.1 绘制顺序

```
GridManager2D (地形)
  → ResourceManager2D (资源点)
  → FogOfWar2D (战争迷雾)
  → TerritoryManager2D (领土边界)
  → BuildingManager2D (建筑)
  → UnitManager2D (单位)
  → GatheringManager2D (采集)
  → NeutralUnitManager2D (中立单位)
  → DragonPortalManager2D (传送门)
  → UI CanvasLayer (界面)
```

### 21.2 动画系统

- 所有单位使用 `_draw()` + `draw_texture_rect_region()` 渲染
- 水平式 SpriteStrip PNG 贴图
- 每单位类型定义：各状态帧数、帧尺寸、绘制尺寸、持续时间
- Idle 动画：实时时钟驱动（Time.get_ticks_msec()）
- 其他状态：Tween 驱动（t 0→1）

### 21.3 建筑贴图配置

建筑纹理定义于 `data/building_texture_fit.json`，包含：
- 占地面积（footprint）
- 偏移量（offset）
- 缩放（scale）
- 纹理路径（texture path）
